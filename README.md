# Amazon Clone 🛒

A front-end clone of the Amazon shopping website, built using HTML and CSS by following the Apna College YouTube tutorial.

## 🚀 Live Demo

[View Amazon Clone](https://padampathak64-sys.github.io/amazon-clone/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome Icons

## ✨ Features

- Amazon-inspired navigation bar
- Search bar UI with category selection
- Delivery location section
- Sign-in and account section
- Returns and orders section
- Product category layout
- Custom styling and hover effects

## 📂 Project Structure

```text
Amazon-Clone/
├── index.html
├── style.css
└── images/
    └── amazon_logo.png
```

## 📚 What I Learned

- Structuring webpages using HTML
- Styling layouts using CSS
- Using Flexbox for alignment
- Working with images and relative file paths
- Using Git and GitHub to manage and publish a project

## 🔮 Future Improvements

- Make the website responsive
- Add interactive features using JavaScript
- Implement product search and cart functionality
- Explore backend development and database integration
